# Proyecto 20 — Agente que aprende a jugar

Elige uno:
- **A.** DQN en PyTorch (MPS/CPU) para `LunarLander-v3` de gymnasium (meta: recompensa media ≥ 200).
- **B.** PPO desde cero para `CartPole-v1` y `Acrobot-v1`.
- **C.** Mini-AlphaZero para Conecta-4 reutilizando el motor del módulo 06.

## Entregables
Código, curvas de aprendizaje con ≥ 3 semillas (media ± desviación), ablación de un componente (sin replay, sin baseline, etc.), video/GIF del agente, reporte.

## Rúbrica (100 pts)
| Criterio | Pts |
|---|---|
| Implementación correcta y legible | 30 |
| Alcanza el objetivo de desempeño | 20 |
| Rigor experimental (semillas, ablación) | 25 |
| Análisis e interpretación | 25 |
