# Módulo 23 — Investigación y proyecto final (capstone)

**Duración:** 8–12 semanas (~120 h) · **Prerrequisitos:** todo el curso
Corresponde al eje BUAP *Educación para la Investigación*.

## Objetivos
- Leer papers de forma eficiente y crítica.
- Reproducir un resultado publicado con rigor estadístico.
- Diseñar, ejecutar y comunicar una investigación original o un sistema de IA completo.

## Contenido
1. Cómo leer un paper (método de las tres pasadas, Keshav) → `teoria.md`.
2. [papers-clave.md](papers-clave.md): 25 papers que todo experto debe conocer, con ruta de lectura.
3. Rigor experimental: semillas, intervalos, pruebas estadísticas, ablaciones, comparaciones justas.
4. Plantillas: [plantillas/reproduccion.md](plantillas/reproduccion.md), [plantillas/propuesta.md](plantillas/propuesta.md), [plantillas/reporte-final.md](plantillas/reporte-final.md).
5. Comunicar: escribir en LaTeX/Markdown, figuras, póster/charla de 15 min, publicar código.
6. Comunidad: arXiv, OpenReview, Papers with Code, conferencias (NeurIPS, ICML, ICLR, ACL, CVPR, AAAI) y la comunidad mexicana (MICAI, SMIA, COMIA).

Tests (10 %), fichas de lectura (15 %), reproducción de paper (25 %), **capstone (50 %)**.
